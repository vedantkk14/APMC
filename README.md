# Inward-Outward & Admin Management System

A frontend web interface designed to efficiently track the inward and outward movement of resources and documents, complete with an administrative dashboard UI.

## 🛠️ Technologies Used
* **HTML5** for page structure
* **CSS3** for styling and responsive layout
* **JavaScript** for frontend logic and interactivity

## 📁 Repository Structure

* `admin_mis/`: Contains the UI and frontend logic for the administrative dashboard and the basic login interface.
* `inward_outward/`: Houses the interfaces and modules responsible for the inward and outward tracking screens.
